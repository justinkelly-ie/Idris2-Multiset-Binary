# ⚡ Idris2-Multiset-Binary

**Constructive Boolean Algebras & Bit Vector Transforms for Idris 2**

`Idris2-Multiset-Binary` provides discrete truth-value logic and bit vector transform primitives for state classification in the physical universe framework.

---

## 🚀 Building & Installing

Built with Idris 2 (`0.8.0`):

```bash
idris2 --build Idris2-Multiset-Binary.ipkg
idris2 --install Idris2-Multiset-Binary.ipkg
```
