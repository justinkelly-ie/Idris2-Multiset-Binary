# Idris2-Multiset-Binary

[![Idris 2 Verification](https://img.shields.io/badge/Idris_2-0.8.0-blue.svg)](https://www.idris-lang.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**Layer 2b Binary Multiset Polynomials, Boolean Logic & Functional Probability**

`Idris2-Multiset-Binary` provides algebraic binary logic representations using multiset polynomials and Möbius transforms:

- **`Logic.BoolePolynumber`**: Binary generating polynomials over discrete `Bit` multisets.
- **`Logic.MobiusTransform`**: Spectral 2D/3D Möbius inversion transforms linking binary state space to manifest grid dimensions.
- **`Logic.Circuit`**: Functional probability, syllogisms, and digital logic gate circuits.

## 🚀 Building & Installing

```bash
idris2 --build Idris2-Multiset-Binary.ipkg
idris2 --install Idris2-Multiset-Binary.ipkg
```
